# 02a. 창작마당·모드 사이트 조사표

> 조사일: 2026-10-12 · 범위: Steam 창작마당(appid 1468810), 모드 배포 사이트, 공개 소스 저장소
> 조사 방법: 창작마당 페이지 열람(중국어 간체 표시), Steam 공개 Web API `ISteamRemoteStorage/GetPublishedFileDetails`, 웹 검색, GitHub 페이지·API 열람. 로그인·구독·내려받기는 하지 않았다.

## 1. 요약

- 창작마당의 "바로 사용 가능한 아이템"은 **16,358개**다(인기순 목록 페이지 표시 기준).
- 기준 문서의 후보 10종 중 **확인 5, 불일치 5**다. 불일치 5건은 링크가 개별 모드가 아니라 컬렉션이거나 검색 링크였던 것으로, 실제 모드 ID를 찾아 기록했다. 접근 불가는 없다.
- 이 프로젝트와 기능이 직접 겹치는 **치트·편집기 모드가 이미 여러 개** 있다. 구독 수 기준으로 `【大鬼】工具盒`(42.9만), `修改器`(13.9만), `【简易自用版】鬼谷八荒内置修改器`(4.4만)이 크다.
- **신규 경지를 추가하는 모드는 찾지 못했다.** "境界" 검색 결과의 경지 모드는 모두 기존 경지의 이름·UI를 바꾸는 것이다(기준 문서 5장의 우려와 일치).
- 공개 소스 저장소 3곳을 확인했다. 셋 다 공식 `ModProject` 구조를 쓴다. 그중 `4azuo/GuiGuBaHuang-ModLib`만 라이선스(MIT)가 명시되어 있다.
- 창작마당 모드의 갱신일은 2022년 중반부터 2026년까지 넓게 퍼져 있다. 기준 문서의 공법 계열 후보는 대부분 2022~2023년에 갱신이 멈췄고, 댓글에 최신 버전 비호환 보고가 있다.

## 8. 이 프로젝트에 주는 시사점

1. **경로 판정의 근거**: 치트·편집기 모드, UI 프레임워크, 공개 소스 저장소가 모두 공식 `ModProject` 구조(`ModCode/ModMain` + `ModExcel` + `ModAssets`)를 쓴다. 독립 MelonMod 형태로 배포된 사례는 Nexus의 ChatAi 하나만 확인했다.
2. **차별점이 필요하다**: 수치 편집·아이템 지급·NPC 편집은 이미 구독 수십만의 모드가 제공한다. 기준 문서가 내세운 "읽기 → 검증 → 백업 → 변경 → 재조회"와 변경 이력, 호환성 진단이 차별점이 될 수 있는지는 기존 모드를 실제로 써 봐야 판단할 수 있다(이 설치본으로는 구독 불가).
3. **UI 진입점 사례**: 단축키(F2, F5, F9, `` ` ``, Y), 주 화면 아이콘, 기존 게임 화면에 버튼 추가(기술 화면의 "技能成长系统", 문파 영각의 "参悟功法"). 기준 문서의 F8은 `成长型功法体系`가 기술 성장 화면에서 초기화 키로 쓴다.
4. **대상 선택 방식**: `修改器`는 "지금 열려 있는 NPC 정보 화면"을 편집 대상으로 삼는다. 별도 NPC 검색 UI 없이 대상을 정하는 간단한 방법이다.
5. **상한과 부작용**: 속성 상한 21억, 행운 200 초과 시 드랍 소실 같은 실제 한계가 모드 설명에 적혀 있다. v0.1의 검증 항목으로 삼는다.
6. **신규 경지는 선행 사례가 없다**: 경지 모드는 전부 이름·UI 교체다. 기준 문서가 신규 경지를 별도 프로젝트로 분리한 판단을 뒷받침한다.
7. **공법 계열 모드의 노후화**: 2022~2023년에 멈춘 공법 모드에 최신 버전 비호환 보고가 달려 있다. 게임 업데이트로 공법 관련 내부 구조가 바뀐 적이 있다는 뜻이므로, 기준 문서의 `GameVersionAdapter` 격리 원칙이 공법 영역에서 특히 필요하다.
8. **코드 없는 치트**: 기연·극·기운 설정만으로 메뉴와 보정을 만든 모드가 있다. 일부 기능은 `ModExcel`만으로 구현할 수 있다.
