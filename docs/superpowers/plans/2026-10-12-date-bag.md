# 날짜 고정·변경과 가방 칸 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 편집기에 날짜 고정, 게임의 날짜 진행 실행(+1·+5·+10일, 달 넘기기), 달력 직접 지정, 가방 칸 ±10을 넣는다.

**Architecture:** 날짜는 새 `TimeService`가, 가방은 새 `BagService`가 맡고 화면(`EditorWindow`)은 두 서비스만 부른다. 날짜 고정은 `WorldUnitBase.AddResidueDay`와 `UIMapMainPlayerInfo.OnSkipMonth`에 Harmony Prefix를 거는 방식이고, 가방 칸은 `dynUnitData.propGridNum`에 덧셈 핸들러를 걸고 세이브별 값을 파일에 기억했다가 60프레임마다 빠졌는지 확인해 다시 건다. 검증은 개발 명령과 검증 스크립트로 게임에서 한다.

**Tech Stack:** C# 7.3 / `net472`, MelonLoader 0.5.4(IL2CPP 프록시), HarmonyLib(`MelonLoader\0Harmony.dll`, 이미 참조됨), uGUI, PowerShell 7, `tools/DevRemote`(화면 밖 게임 조작)

**Spec:** `docs/superpowers/specs/2026-10-12-date-bag-design.md`

## Global Constraints

- 작업 브랜치는 `develop`에서 분기한 `feat/date-bag`이다. `main`·`develop`에 직접 커밋하지 않는다. 끝나면 `git merge --no-ff`로 `develop`에 병합한다. 원격은 없다. 커밋 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`을 붙인다.
- 게임 폴더(`E:\Games\Tale of Immortal`)는 읽기 전용이다. 예외는 `ModExportData\Mod_sWP6UL\ModCode\dll\MOD_sWP6UL.dll`(편집기 설치)뿐이며, 이 계획에서는 `tools/DevRemote/session.ps1`과 `tools/install.ps1`만 그 파일을 바꾼다.
- 사용자의 게임이 켜져 있으면 임의로 끄지 않는다. 종료를 요청하고 기다린다(`session.ps1 -Begin`이 그 경우 멈춘다).
- 세이브를 바꾸는 시험은 백업 → 시험 → 복원 → 일치 확인 순서다. 게임은 달이 넘어갈 때 자동 저장하므로 모든 회차를 `session.ps1 -End`로 끝낸다.
- 두 구성이 모두 빌드돼야 한다: `dotnet build src/ModCode/ModMain/ModMain.csproj -c Release`(개발)와 `-p:DevTools=false`(배포). `Dev\` 밖의 코드가 `Dev\`의 형식을 참조하면 안 된다. `#if DEVTOOLS`로 감싼 것은 된다.
- `bin\Release`에는 `MOD_sWP6UL.dll` 하나만 있어야 한다. 새 참조를 추가하지 않는다.
- 값의 범위는 스펙 그대로다: 날짜는 연 1~9999, 월 1~12, 일 1~30. 가방 추가 칸은 0~500, 단위 10. 덧셈 태그는 `"TlToybox"`, 저장 파일은 `<TlToybox 폴더>\bag-slots.txt`, Harmony ID는 `TlToybox.time`.
- 화면 문구와 문서는 한국어다. 문서에는 어셈블리나 게임에서 실제로 확인한 이름만 적고, 확인하지 못한 것은 "미확인"과 사유를 적는다.
- 코드는 기존 파일의 모양을 따른다: 4칸 들여쓰기, 모든 `if`에 중괄호, 속성은 `get { return ...; }`, 서비스는 결과를 문장으로 돌려준다.
- PowerShell: 변수 이름은 대소문자를 구분하지 않는다(`$T`와 `$t`가 같은 변수). 파일 삭제는 `[IO.File]::Delete` 또는 Bash의 `rm`을 쓴다. 게임 종료는 창 닫기 요청으로 한다(`session.ps1`이 한다. `Stop-Process`는 권한 검사에 막힌다).
- 모든 git·파일 명령은 절대경로 또는 `git -C E:\TlToybox`를 쓴다.
- 서브에이전트에 위임할 때는 해당 Task의 본문을 지시문에 직접 넣고, "이 작업(Task N)만 수행하라. 끝나면 보고하고 정지하라. 다른 Task로 진행하지 말라. 명세에 없는 코드를 추측·즉흥 구현하지 말라. 명세가 부족하면 멈추고 `NEEDS_CONTEXT`로 보고하라. 모든 git/파일 명령에 절대경로 또는 `-C <레포 절대경로>`를 사용하라."를 포함한다.

## Review Focus

스펙이 암시하지만 놓치기 쉬운 조건들이다. 각 항목의 시험은 담당 Task의 검증 스크립트에 들어 있다.

1. **남은 날이 0인 달("이번 달의 시간을 전부 사용했습니다")에서 날짜를 직접 지정한다.** → 띠가 사라지고 다시 행동할 수 있어야 한다. (Task 2: `tset out of a used-up month`, `banner is gone`, `walking works again`)
2. **직접 지정의 입력 칸이 비었거나 숫자가 아니다.** → 아무것도 바꾸지 않고 이유를 알린다. (Task 2: `empty day is rejected`)
3. **날짜 고정 중에 편집기의 +N일, 달 넘기기, 직접 지정을 누른다.** → 앞의 둘은 거부하고 직접 지정은 된다. (Task 3: `tadv refused while frozen`, `tskip refused while frozen`, `tset works while frozen`)
4. **`bag-slots.txt`에 깨진 줄이나 범위 밖의 값이 있다.** → 깨진 줄은 무시하고 값은 0~500으로 자르며, 게임이 멈추거나 경고가 쌓이지 않는다. (Task 4: `bag-corrupt`)
5. **세이브에 들어가기 전(주 화면)의 60프레임 점검, 그리고 상한·하한에서의 ±10.** → 아무것도 걸지 않고 경고도 없다. 상한·하한에서는 거부한다. (Task 4: `no warning from the background tick`, `minus at zero is refused`, `plus at the limit is refused`)

`tools/DevRemote/session.ps1`:

```powershell
# 게임 검증 한 회차의 시작과 끝을 묶는다(docs/06-handoff.md 5절의 절차).
#   -Begin <이름>   게임이 꺼져 있는지 확인 → 빌드 → 세이브를 .devremote\save-backup-<이름>으로 복사
#                   → 게임에 설치 → 화면 밖에서 실행해 1번 세이브 진입
#   -Restart        이 스크립트가 띄운 게임을 닫고 다시 띄운다(세이브와 설치된 DLL은 그대로). 저장 후 재시작 확인용
#   -End <이름>     이 스크립트가 띄운 게임을 닫고 → 세이브를 복사본으로 되돌려 일치를 확인 → 설치돼 있던 DLL을 되돌린다
#   -ReleaseBuild   -Begin과 함께 쓴다. 개발 도구를 뺀 배포 구성으로 빌드해 설치한다. 준비 로그가 없으므로 30초를 기다린다
# 게임은 달이 넘어갈 때 자동 저장하므로, 저장 명령을 쓰지 않은 회차도 -End로 되돌린다.
param([string]$Begin = '', [string]$End = '', [switch]$Restart, [switch]$ReleaseBuild,
  [string]$GameDir = 'E:\Games\Tale of Immortal', [string]$ModId = 'sWP6UL')
$ErrorActionPreference = 'Stop'
$repo = Split-Path -Parent (Split-Path -Parent $PSScriptRoot)
$dir = Join-Path $repo '.devremote'
$save = Join-Path $env:USERPROFILE 'AppData\LocalLow\guigugame\guigubahuang\Steam\CacheData'
$installed = Join-Path $GameDir "ModExportData\Mod_$ModId\ModCode\dll\MOD_$ModId.dll"
$keptDll = Join-Path $dir 'session-installed.dll'
$pidFile = Join-Path $dir 'session.pid'
$modeFile = Join-Path $dir 'session.mode'
$flag = Join-Path $dir 'park.flag'

function Launch {
  [IO.File]::WriteAllText($flag, '')
  $blind = (Test-Path $modeFile) -and ([IO.File]::ReadAllText($modeFile).Trim() -eq 'release')
  $enter = Join-Path $PSScriptRoot 'enter.ps1'
  $lines = if ($blind) { & $enter -GameDir $GameDir -Launch -Direct -BlindWaitSeconds 30 } else { & $enter -GameDir $GameDir -Launch -Direct }
  $lines
  $game = Get-Process guigubahuang -ErrorAction SilentlyContinue | Select-Object -First 1
  if ($game) { [IO.File]::WriteAllText($pidFile, [string]$game.Id) }
  if (-not ($lines -match 'WORLD READY|WAITED')) { throw '세이브 진입에 실패했습니다. -End로 정리한 뒤 원인을 확인합니다.' }
}

# 이 스크립트가 띄운 게임만 닫는다. 창 닫기 요청을 보내고 끝날 때까지 기다린다.
function CloseGame {
  if (-not (Test-Path $pidFile)) { return }
  $id = [int]([IO.File]::ReadAllText($pidFile).Trim())
  $game = Get-Process -Id $id -ErrorAction SilentlyContinue
  if ($game -and $game.ProcessName -eq 'guigubahuang') {
    [void]$game.CloseMainWindow()
    for ($i = 0; $i -lt 60 -and -not $game.HasExited; $i++) { Start-Sleep -Milliseconds 500; $game.Refresh() }
    if (-not $game.HasExited) { throw "게임이 닫히지 않았습니다(pid $id)." }
  }
  [IO.File]::Delete($pidFile)
}

function Snapshot([string]$root) {
  Get-ChildItem -LiteralPath $root -Recurse -File |
    ForEach-Object { $_.FullName.Substring($root.Length) + ' ' + (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash } |
    Sort-Object
}

if ($Begin) {
  if (Get-Process guigubahuang -ErrorAction SilentlyContinue) { throw '게임이 실행 중입니다. 사용자에게 종료를 요청하고 기다립니다(임의로 끄지 않는다).' }
  $bak = Join-Path $dir "save-backup-$Begin"
  if (Test-Path $bak) { throw "복사본이 이미 있습니다: $bak" }
  if (Test-Path $keptDll) { throw "끝내지 않은 회차가 있습니다($keptDll). 먼저 -End로 끝냅니다." }
  $proj = Join-Path $repo 'src\ModCode\ModMain\ModMain.csproj'
  if ($ReleaseBuild) {
    $outDir = Join-Path $env:TEMP "tltoybox-release-$ModId"
    dotnet build $proj -c Release --nologo -p:DevTools=false -p:ModId=$ModId -o $outDir | Select-Object -Last 3
    $dll = Join-Path $outDir "MOD_$ModId.dll"
  } else {
    dotnet build $proj -c Release --nologo | Select-Object -Last 3
    $dll = Join-Path $repo "src\ModCode\ModMain\bin\Release\MOD_$ModId.dll"
  }
  if ($LASTEXITCODE -ne 0) { throw '빌드에 실패했습니다.' }
  Copy-Item -LiteralPath $save -Destination $bak -Recurse
  Copy-Item -LiteralPath $installed -Destination $keptDll
  Copy-Item -LiteralPath $dll -Destination $installed -Force
  [IO.File]::WriteAllText($modeFile, $(if ($ReleaseBuild) { 'release' } else { 'dev' }))
  Launch
}

if ($Restart) {
  CloseGame
  Launch
}

if ($End) {
  $bak = Join-Path $dir "save-backup-$End"
  if (-not (Test-Path $bak)) { throw "복사본이 없습니다: $bak" }
  CloseGame
  if (Get-Process guigubahuang -ErrorAction SilentlyContinue) { throw '게임이 아직 실행 중입니다.' }
  foreach ($file in $flag, $modeFile) { if (Test-Path $file) { [IO.File]::Delete($file) } }
  robocopy $bak $save /MIR /NJH /NJS /NP /NDL /NFL | Out-Null
  if ($LASTEXITCODE -ge 8) { throw "세이브 복원에 실패했습니다(robocopy $LASTEXITCODE)." }
  $diff = Compare-Object (Snapshot $bak) (Snapshot $save)
  if ($diff) { $diff | ForEach-Object { "$($_.SideIndicator) $($_.InputObject)" }; throw '세이브가 복사본과 다릅니다.' }
  'SAVE RESTORED AND IDENTICAL'
  if (Test-Path $keptDll) {
    Copy-Item -LiteralPath $keptDll -Destination $installed -Force
    [IO.File]::Delete($keptDll)
    'INSTALLED DLL RESTORED'
  }
}
exit 0
```

`src/ModCode/ModMain/Dev/DevCommandsTime.cs`:

```csharp
using System.Text;
using UnityEngine;

namespace MOD_sWP6UL
{
    // 개발 전용. 날짜와 가방의 상태를 읽고, 날짜를 쓰는 게임 행동(이동·수련)을 실행하는 검증 명령.
    // tools/research/datebag-check.ps1이 이 명령들의 출력 모양에 의존한다.
    internal static class DevCommandsTime
    {
        public static string Execute(string[] p)
        {
            WorldUnitBase me = g.world.playerUnit;
            switch (p[0])
            {
                case "wdate":
                    return Date(me);
                case "grid":
                    return Grid(me);
                case "wmove":
                    {
                        Vector2Int before = me.data.unitData.GetPoint();
                        var target = new Vector2Int(before.x + int.Parse(p[1]), before.y + int.Parse(p[2]));
                        int can = me.IsCreateAction(new UnitActionMovePlayer(target), false);
                        int code = can == 0 ? me.CreateAction(new UnitActionMovePlayer(target), false) : -1;
                        Vector2Int after = me.data.unitData.GetPoint();
                        return "IsCreateAction=" + can + " CreateAction=" + code + " point " + before.x + "," + before.y
                            + " -> " + after.x + "," + after.y + "; " + Date(me);
                    }
                case "wexp":
                    {
                        Vector2Int point = me.data.unitData.GetPoint();
                        var saved = me.data.unitData.propertyData;
                        var probe = new UnitActionGridGetExp(point);
                        int can = me.IsCreateAction(probe, false);
                        int before = saved.exp;
                        int code = can == 0 ? me.CreateAction(new UnitActionGridGetExp(point), false) : -1;
                        return "IsCreateAction=" + can + " day=" + probe.day + " CreateAction=" + code + " exp " + before
                            + " -> " + saved.exp + "; " + Date(me);
                    }
                case "gridfill":
                    return Fill(me, int.Parse(p[1]), p.Length > 2 ? int.Parse(p[2]) : -1);
                default:
                    return null;
            }
        }

        private static string Date(WorldUnitBase me)
        {
            var run = g.world.run;
            var date = GameTool.DayToDate(g.data.world.worldDay);
            return "worldDay=" + g.data.world.worldDay + " date=" + date[0] + "-" + date[1] + "-" + date[2]
                + " roundDay=" + run.roundDay + "/" + run.roundDayMax
                + " residueDay=" + me.data.unitData.residueDay
                + " age=" + me.data.unitData.propertyData.age
                + " moveDay=" + UnitActionMovePlayer.GetCurDay(me);
        }

        private static string Grid(WorldUnitBase me)
        {
            var props = me.data.unitData.propData;
            DynInt grid = me.data.dynUnitData.propGridNum;
            var sb = new StringBuilder();
            sb.Append("cur=").Append(props.GetGridCurNum()).Append(" max=").Append(props.GetGridMaxNum())
                .Append(" base=").Append(grid.baseValue).Append(" add=[");
            var adds = grid.allAddCall;
            for (int i = 0; adds != null && i < adds.Count; i++)
            {
                sb.Append(i == 0 ? "" : ", ").Append(adds[i].t2).Append('=').Append(adds[i].t1.Invoke());
            }
            sb.Append("] items=").Append(props.allProps.Count);
            return sb.ToString();
        }

        // 가지고 있지 않은 아이템을 한 개씩 지급해 가방 칸을 채운다. 지급이 안 되면 거기서 멈춘다.
        private static string Fill(WorldUnitBase me, int count, int mainType)
        {
            var props = me.data.unitData.propData;
            int before = props.GetGridCurNum();
            int given = 0;
            string stopped = "";
            foreach (ItemCatalog.Entry entry in ItemCatalog.Find("", mainType, -1))
            {
                if (given >= count)
                {
                    break;
                }
                if (props.GetPropsNum(entry.Id) > 0)
                {
                    continue;
                }
```

```csharp
    // 구조와 쓰기 경로는 docs/superpowers/specs/2026-10-12-date-bag-design.md 3절에서 실측했다.
    //   누적 일수 g.data.world.worldDay, 달 안의 경과 g.world.run.roundDay, 플레이어의 남은 일수 unitData.residueDay.
    //   플레이어의 행동은 WorldUnitBase.AddResidueDay로 날짜를 쓴다. WorldRunMgr.AddDay를 직접 부르면 남은 일수가 어긋난다.
    internal static class TimeService
    {
        public const int MaxYear = 9999;

        private static WorldUnitBase Player
        {
            get { return g.world.playerUnit; }
        }

        public static int WorldDay
        {
            get { return g.data.world.worldDay; }
        }

        public static int ResidueDay
        {
            get { return Player.data.unitData.residueDay; }
        }

        // 누적 일수의 연·월·일. 게임의 변환을 그대로 쓴다.
        public static int[] ToDate(int worldDay)
        {
            var date = GameTool.DayToDate(worldDay);
            return new[] { date[0], date[1], date[2] };
        }

        public static string DateText(int worldDay)
        {
            int[] date = ToDate(worldDay);
            return date[0] + "년 " + date[1] + "월 " + date[2] + "일";
        }

        public static string Describe()
        {
            return "제 " + DateText(WorldDay) + " (누적 " + WorldDay + "일 · 이번 달 남은 날 " + ResidueDay + ")";
        }

        // 연·월·일을 누적 일수로 바꾼다. 게임의 변환으로 되돌려 같은 날짜가 나올 때만 성공한다(달력 규칙이 바뀌었을 때의 안전장치).
        public static bool TryToWorldDay(int year, int month, int day, out int worldDay, out string error)
        {
            worldDay = 0;
            if (year < 1 || year > MaxYear || month < 1 || month > 12 || day < 1 || day > 30)
            {
                error = "날짜: 연 1~" + MaxYear + ", 월 1~12, 일 1~30으로 입력하세요.";
                return false;
            }
            int ticks = g.world.run.roundDayMax + 1;
            worldDay = (year - 1) * 12 * ticks + (month - 1) * ticks + (day - 1);
            int[] back = ToDate(worldDay);
            if (back[0] != year || back[1] != month || back[2] != day)
            {
                error = "날짜: 게임의 달력 계산과 맞지 않아 적용하지 않았습니다(" + year + "-" + month + "-" + day + " -> "
                    + back[0] + "-" + back[1] + "-" + back[2] + ").";
                return false;
            }
            error = null;
            return true;
        }

        // 지도 화면의 날짜 표기와 "이번 달의 시간을 전부 사용" 띠를 다시 그린다.
        private static void RefreshHud()
        {
            UIMapMain map = g.ui.GetUI<UIMapMain>(UIType.MapMain);
            if (map != null && map.uiPlayerInfo != null)
            {
                map.uiPlayerInfo.UpdateUI();
            }
        }

        // 게임의 날짜 진행을 실행한다. 이번 달 남은 날까지만 진행한다.
        public static string Advance(int days)
        {
            if (days < 1)
            {
                return "날짜: 1일 이상이어야 합니다.";
            }
            WorldUnitBase player = Player;
            int residue = player.data.unitData.residueDay;
            if (residue <= 0)
            {
                return "날짜: 이번 달 남은 날이 없습니다. 게임에서 달을 넘기거나 날짜를 직접 지정하세요.";
            }
            int step = Math.Min(days, residue);
            string backupError = SaveBackup.EnsureOnce();
            if (backupError != null)
            {
                return backupError + " 변경을 중단했습니다.";
            }
            int before = WorldDay;
            player.AddResidueDay(step, false);
            int after = WorldDay;
            int afterResidue = player.data.unitData.residueDay;
            RefreshHud();
            bool verified = after == before + step && afterResidue == residue - step;
            ChangeLog.Add("세계", "날짜", DateText(before), DateText(after), verified);
            if (!verified)
            {
                return "날짜: 진행을 실행했지만 값이 기대와 다릅니다(누적 " + before + " -> " + after + ", 남은 날 " + residue + " -> " + afterResidue + ").";
            }
            string head = step < days ? "이번 달 남은 날이 " + residue + "일이라 " + step + "일만 진행했습니다" : step + "일 진행";
            return "날짜: " + head + " (" + DateText(before) + " -> " + DateText(after) + ", 이번 달 남은 날 " + afterResidue + ")";
        }

        // 게임의 달 넘기기 확인 창을 연다. 진행은 게임의 절차다. 열었으면 null, 못 열면 이유를 돌려준다.
        public static string OpenSkipMonth()
        {
            UIMapMain map = g.ui.GetUI<UIMapMain>(UIType.MapMain);
            if (map == null || map.uiPlayerInfo == null)
            {
                return "달 넘기기: 지도 화면에서만 할 수 있습니다.";
            }
            // 달이 넘어가면 게임이 자동 저장한다.
            string backupError = SaveBackup.EnsureOnce();
            if (backupError != null)
            {
                return backupError + " 변경을 중단했습니다.";
            }
            map.uiPlayerInfo.OnSkipMonth();
            return null;
        }

        // 달력을 직접 지정한다. 누적 일수, 달 안의 경과, 플레이어의 남은 일수를 함께 쓴다.
        // 그 사이의 월말 처리는 일어나지 않고, 날짜 기준 기록(임무 기한 등)은 건드리지 않는다.
        public static string SetDate(int year, int month, int day)
        {
            int target;
            string error;
            if (!TryToWorldDay(year, month, day, out target, out error))
            {
                return error;
            }
            int before = WorldDay;
            if (target == before)
            {
                return "날짜: 이미 " + DateText(before) + "입니다.";

            if (backupError != null)
            {
                return backupError + " 변경을 중단했습니다.";
            }
            WorldUnitBase player = Player;
            var run = g.world.run;
            int inMonth = day - 1;
            int residue = run.roundDayMax - inMonth;
            g.data.world.worldDay = target;
            run.roundDay = inMonth;
            player.data.unitData.residueDay = residue;
            RefreshHud();
            bool verified = WorldDay == target && run.roundDay == inMonth && player.data.unitData.residueDay == residue;
            ChangeLog.Add("세계", "날짜(직접 지정)", DateText(before), DateText(WorldDay), verified);
            return verified
                ? "날짜: " + DateText(before) + " -> " + DateText(target) + " (누적 " + before + "일 -> " + target + "일)"
                : "날짜: 썼지만 재조회 값이 다릅니다(누적 " + WorldDay + ", 달 안 " + run.roundDay + ", 남은 날 " + player.data.unitData.residueDay + ").";
        }
    }
}
```

```csharp
                return null;
```

`src/ModCode/ModMain/Services/BagService.cs`:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using MelonLoader;
using UnhollowerRuntimeLib;

namespace MOD_sWP6UL
{
    // 가방 칸. 게임의 용량(dynUnitData.propGridNum)에 덧셈을 건다.
    // 건 값은 저장되지 않으므로(실측) 세이브별 추가 칸을 파일에 기억하고, 세계에 들어올 때마다 다시 건다.
    // 줄여서 넘치는 아이템은 사라지지 않고 남는다(실측). 근거: docs/superpowers/specs/2026-10-12-date-bag-design.md 3.4절.
    internal static class BagService
    {
        public const int Step = 10;
        public const int MaxExtra = 500;

        private const string Tag = "TlToybox";
        private const string FileName = "bag-slots.txt";

        private static DynInt.DynObjectAddHandler handler;
        private static int applied;                    // 핸들러가 돌려주는 값
        private static Dictionary<string, int> saved;  // playerUnitID -> 추가 칸. null이면 아직 읽지 않았다
        private static int frames;
        private static bool warned;

        private static string FilePath
        {
            get { return Path.Combine(ChangeLog.DataDir, FileName); }
        }

        private static int Clamp(int value)
        {
            return Math.Max(0, Math.Min(MaxExtra, value));
        }

        // 파일을 읽어 saved를 채운다. 읽지 못하면 false와 이유를 돌려준다. 해석할 수 없는 줄은 건너뛴다.
        private static bool TryLoad(out string error)
        {
            error = null;
            if (saved != null)
            {
                return true;
            }
            try
            {
                var map = new Dictionary<string, int>();
                if (File.Exists(FilePath))
                {
                    foreach (string line in File.ReadAllLines(FilePath))
                    {
                        string trimmed = line.Trim();
                        int eq = trimmed.IndexOf('=');
                        int value;
                        if (trimmed.Length == 0 || trimmed[0] == '#' || eq <= 0 || !int.TryParse(trimmed.Substring(eq + 1).Trim(), out value))
                        {
                            continue;
                        }
                        map[trimmed.Substring(0, eq).Trim()] = Clamp(value);
                    }
                }
                saved = map;
                return true;
            }
            catch (IOException e)
            {
                error = e.Message;
                return false;
            }
            catch (UnauthorizedAccessException e)
            {
                error = e.Message;
                return false;
            }
        }

        private static void Save(Dictionary<string, int> map)
        {
            Directory.CreateDirectory(ChangeLog.DataDir);
            var lines = new List<string> { "# 세이브별 가방 추가 칸. <플레이어 단위 ID>=<칸 수>" };
            foreach (KeyValuePair<string, int> pair in map)
            {
                if (pair.Value > 0)
                {
                    lines.Add(pair.Key + "=" + pair.Value);
                }
            }
            File.WriteAllLines(FilePath, lines.ToArray());
        }

        // 현재 세이브의 추가 칸. 세계가 준비되지 않았거나 파일을 읽지 못하면 0.
        public static int Extra
        {
            get
            {
                string error;
                if (!EditService.WorldReady || !TryLoad(out error))
                {
                    return 0;
                }
                int value;
                saved.TryGetValue(g.data.world.playerUnitID, out value);
                return value;
            }
        }

        public static string Describe()
        {
            var props = g.world.playerUnit.data.unitData.propData;
            return "가방 " + props.GetGridCurNum() + "/" + props.GetGridMaxNum() + " (편집기 추가 +" + Extra + ")";
        }

        private static bool IsAttached(DynInt grid)
        {
            var calls = grid.allAddCall;
            for (int i = 0; calls != null && i < calls.Count; i++)
            {
                if (calls[i].t2 == Tag)
                {
                    return true;
                }
            }
            return false;
        }

        // 현재 플레이어의 용량에 extra를 건다. 이미 걸린 것은 떼고 새 값으로 다시 건다. 0이면 걸지 않는다.
        private static void Apply(WorldUnitBase player, int extra)
        {
            DynInt grid = player.data.dynUnitData.propGridNum;
            if (handler != null && IsAttached(grid))
            {
                grid.DelValue(handler);
            }
            applied = extra;
            if (extra <= 0)
            {
                return;
            }
            if (handler == null)
            {
                handler = DelegateSupport.ConvertDelegate<DynInt.DynObjectAddHandler>(new Func<int>(() => applied));
            }
            grid.AddValue(handler, Tag);
        }

        // 추가 칸을 delta만큼 바꾼다(0~MaxExtra). 파일에 먼저 쓰고, 쓰지 못하면 게임 값도 바꾸지 않는다.
        public static string Change(int delta)
        {
            if (!EditService.WorldReady)
            {
                return "가방: 세이브에 진입한 뒤에 사용할 수 있습니다.";
            }
            string error;
            if (!TryLoad(out error))
            {
                return "가방: 저장 파일을 읽지 못해 바꾸지 않았습니다(" + error + ").";
            }
            string key = g.data.world.playerUnitID;
            int before;
            saved.TryGetValue(key, out before);
            int after = Clamp(before + delta);
            if (after == before)
            {
                return "가방: 추가 칸은 0~" + MaxExtra + " 사이입니다(현재 +" + before + ").";
            }
            var next = new Dictionary<string, int>(saved);
            next[key] = after;
            try
            {
                Save(next);
            }
            catch (IOException e)
            {
                return "가방: 저장 파일을 쓰지 못해 바꾸지 않았습니다(" + e.Message + ").";
            }
            catch (UnauthorizedAccessException e)
            {
                return "가방: 저장 파일을 쓰지 못해 바꾸지 않았습니다(" + e.Message + ").";
            }
            saved = next;

            WorldUnitBase player = g.world.playerUnit;
            var props = player.data.unitData.propData;
            int maxBefore = props.GetGridMaxNum();
            Apply(player, after);
            int maxAfter = props.GetGridMaxNum();
            bool verified = maxAfter - maxBefore == after - before;
            ChangeLog.Add(EditService.NameOf(player), "가방 추가 칸", "+" + before, "+" + after, verified);
            string text = "가방: 추가 칸 +" + before + " -> +" + after + " (용량 " + maxBefore + " -> " + maxAfter + ")";
            if (!verified)
            {
                text += " 용량이 기대한 만큼 바뀌지 않았습니다.";
            }
            int used = props.GetGridCurNum();
            if (used > maxAfter)
            {
                text += " 가방이 넘칩니다(" + used + "/" + maxAfter + "). 아이템은 남아 있고, 비우기 전에는 새 아이템을 받을 수 없습니다.";
            }
            return text;
        }

        // 걸려 있어야 할 추가 칸이 빠져 있으면 다시 건다. 세이브에 들어온 직후와 인물 데이터가 새로 만들어진 경우를 처리한다.
        public static void EnsureApplied()
        {
            try
            {
                if (!EditService.WorldReady)
                {
                    return;
                }
                WorldUnitBase player = g.world.playerUnit;
                if (player.data == null || player.data.dynUnitData == null || player.data.dynUnitData.propGridNum == null)
                {
                    return;
                }
                int extra = Extra;
                bool attached = IsAttached(player.data.dynUnitData.propGridNum);
                if (extra > 0 && (!attached || applied != extra))
                {
                    Apply(player, extra);
                }
                else if (extra == 0 && attached)
                {
                    Apply(player, 0);
                }
            }
            catch (Exception e)
            {
                if (!warned)
                {
                    warned = true;
                    MelonLogger.Msg("[TlToybox] 가방 추가 칸을 적용하지 못했습니다: " + e.Message);
                }
            }
        }
```
