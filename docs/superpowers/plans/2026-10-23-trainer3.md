# 트레이너 3차 (가) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 법보 경지·단계(지급 포함, 비율 0 지급 고침), 기령 친밀도 최대, 심법 전승 붙이기·떼기, 참오 결과 최대 켬/끔을 기존 탭(법보·공법·성공·드롭)에 넣는다.

**Architecture:** 게임 없이 시험할 수 있는 규칙(단계 ↔ 비율, 경지 반복 횟수)은 `Services/TreasureRules.cs`에 두고 단위 시험에 연결한다. 게임 쓰기는 `TreasureService`·`MartialService`·`SuccessService`에 더하고, 탭은 그 서비스만 부른다. 게임 검증은 개발 명령 + `tools/research/*-check.ps1`의 새 부분으로 한다.

**Tech Stack:** C# (net472, MelonLoader 0.5.4, Unhollower IL2CPP, HarmonyLib), PowerShell 7 검사 스크립트.

**Spec:** `docs/superpowers/specs/2026-10-23-trainer3-design.md`

## Global Constraints

- 브랜치 `feat/trainer3`(develop에서 땀). `develop`·`main`에 직접 커밋하지 않는다. 커밋 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 빌드: `dotnet build src/ModCode/ModMain/ModMain.csproj -c Release` 오류 0. 단위 시험: `dotnet run --project tests/ModMain.Tests -c Release`가 `FAILS=0`.
- 게임 검증은 `pwsh tools/DevRemote/session.ps1 -Begin <새 이름> -Fixture base -Exclude 2814696167` … `-End <이름>`, 끝 줄 `SAVE RESTORED AND IDENTICAL`. 회차 이름은 `tr3-1023a`부터 차례로, 다시 쓰지 않는다.
- 단계 대표 비율: 1→60, 2→80, 3→85, 4→95, 5→100, 6→120. 평균 → 단계: ≤60 1, 61~80 2, 81~89 3, 90~99 4, 100~109 5, ≥110 6.
- 경지 상한 10. 경지 10 이상이면 `UnitActionPropArtifactShapeUpgrade`를 부르지 않는다.
- 친밀도 최대값은 `g.conf.artifactSpriteClose.closeMax`(지금 900)에서 읽는다.
- 참오 결과 수치 = `GetPrefixMaxLevel(martialData, item) × 100`. 접미 안에서 공법 값을 쓰지 않는다.
- 사용자에게 보이는 글은 한국어. 모든 쓰기는 `ChangeLog.Add`.
- 기존 개발 명령 `tr`의 출력 꼴은 바꾸지 않는다(`treasure-check.ps1`의 정규식이 줄 끝 `:eq:0]`에 기댄다). 새 정보는 새 명령으로.

## Review Focus

1. 경지 10 법보에 `경지 +1`·`경지 10까지`·지급 경지 10 → 게임 행동을 부르지 않고 경지 10 그대로(Task 2 검사 `grade at 10 is refused`).
2. 게임이 비율을 준 법보(0이 아닌 비율)를 편집기로 하나 더 지급 → 기존 법보 비율은 그대로(Task 3 검사 `existing treasure keeps its rates`).
3. 참오 결과 최대를 켠 채 공법 탭의 `최고`·`+` 단추나 비급 만들기 → 영향 없음(Task 7 검사 `quality buttons are untouched while realize-max is on`).
4. 다른 글(`{"suitID":…}`이 아닌 `valuesStr`)이 든 심법에 전승 붙이기 → 거부, 값 그대로(Task 5 검사 `foreign valuesStr is refused`).
5. 대상이 NPC일 때 법보 강화·친밀도·전승 → 그 NPC에 쓰이고 플레이어는 그대로(Task 2·5 검사 `npc target`).
