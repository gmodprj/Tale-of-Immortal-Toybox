# 배율 탭 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 편집기에 `배율` 탭을 더해 수련치 획득, 전투 중 공법 숙련, 이동의 날짜 소모, 전투 속도의 배율을 단계 버튼으로 켜고 끄며, 기존의 무적과 피해 배율을 세계 탭에서 이 탭으로 옮긴다.

**Architecture:** 화면을 모르는 `Services/RateService.cs`가 배율 값과 Harmony 접두 함수를 갖는다. 패치는 그 배율을 처음 1배가 아닌 값으로 바꿀 때 그 지점에만 건다(`TimeService`의 날짜 고정과 같은 방식). 전투 속도는 패치 없이 매 프레임 `Time.timeScale`을 맞춘다. 화면은 새 `UI/Tabs/RateTab.cs`가 배율 목록을 돌며 줄을 그린다.

**Tech Stack:** C# 7.3 / .NET Framework 4.7.2, Unity 2020.3 IL2CPP + MelonLoader 0.5.4(Unhollower, HarmonyLib), uGUI. 검증은 PowerShell 7 스크립트와 `tools/DevRemote`.

**Spec:** `docs/superpowers/specs/2026-10-13-rate-tab-design.md`

## Global Constraints

- 대상: 귀곡팔황 v1.2.113.259, 게임 폴더 `E:\Games\Tale of Immortal`, 모드 ID `sWP6UL`, 네임스페이스 `MOD_sWP6UL`.
- 참조를 추가하지 않는다. `bin\Release`에는 `MOD_sWP6UL.dll` 하나만.
- 개발 구성과 배포 구성(`-p:DevTools=false`) 모두 경고 0, 오류 0. `Dev\`의 코드를 배포 코드가 참조하지 않는다(`#if DEVTOOLS`로 감싼 것은 된다).
- 배율은 플레이어(`g.world.playerUnit`)의 호출에만 건다. NPC의 호출은 값을 바꾸지 않는다.
- 저장하지 않는다. 게임을 켤 때마다 전부 1배, 무적 꺼짐.
- 패치는 처음 1배가 아닌 값으로 바꿀 때 그 지점에만 한 번 건다. 건 뒤에는 떼지 않는다. 한 번도 쓰지 않은 배율은 게임에 아무것도 걸지 않는다.
- 공법 숙련은 `AddMartialExpInBattle`에만 건다. `AddMartialExp`에는 걸지 않는다(안팎이라 제곱이 된다).
- 접두 함수 안의 예외는 삼키고 원래 값을 통과시킨다. 로그는 배율마다 한 번만 남긴다.
- 인자가 0 이하이면 곱하지 않는다. 곱한 값은 `Int32` 최댓값으로 자른다.
- 전투 속도는 전투 장면에서만 `Time.timeScale`을 쓴다. `Time.timeScale`이 0이면(게임의 일시 정지) 건드리지 않는다.
- 단계: 수련치·공법 숙련 `1, 2, 5, 10, 100` / 이동 `1, 0.5, 0.25, 0.1, 0` / 전투 속도 `1, 1.5, 2, 3`.
- 버튼 이름: `RateExp`, `RateMartial`, `RateMove`, `RateSpeed`, `Multiplier`, `God`, `RateReset`.
- 탭 순서: 능력치 · 자원 · 화폐 · 보관함 · 경지 · 공법 · 운명 · 기예 · NPC · 세계 · 배율 · 안전(`Tab0`~`Tab11`).
- 값을 바꿀 때마다 `ChangeLog.Add("배율", …)`.
- 브랜치: `feat/rate-tab`(이미 있다). `git merge --no-ff`로 `develop`에. 커밋 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 게임 검증은 `tools/DevRemote/session.ps1`의 회차 안에서만, `-Fixture base`로. 회차 이름은 한 번 쓴 것을 다시 쓰지 않는다(이미 쓴 이름: `rate1`, `rate2`, `preset1`, `preset2`). 사용자의 게임이 켜져 있으면 끄도록 알리고 기다린다.
- 코드 모양은 주변과 같게(중괄호는 항상 쓰고 줄을 바꾼다, 들여쓰기 4칸, 주석은 한국어로 "왜"를 적는다). 식 본문 멤버와 문자열 보간은 쓰지 않는다(주변 코드가 쓰지 않는다).

## Review Focus

1. 달을 넘길 때 NPC 수백 명이 `AddExp`와 이동을 부른다 → NPC의 값은 그대로이고 게임이 느려지거나 예외가 나지 않는다. (Task 2 `rates`의 "an NPC gains the plain amount")
2. 수련치가 줄어드는 호출(인자가 음수)이나 0 → 배율이 손해를 키우지 않는다. (Task 2 "a negative amount is not scaled")
3. 전투 속도를 켠 채 전투가 끝나거나 주 화면으로 나감 → `Time.timeScale`이 1로 돌아온다. 지도 화면이 빨라진 채 남지 않는다. (Task 3 "speed returns to 1 when set back", `OnDestroy`. 전투 종료 뒤의 복귀는 Task 3의 수동 확인)
4. 전투 중 게임이 일시 정지(`Time.timeScale` 0)한 동안 → 편집기가 정지를 풀지 않는다. (Task 3 "a paused game stays paused")
5. 날짜 고정과 이동 배율을 함께 켬 → 날짜는 고정이 이긴다(흐르지 않는다). 줄에 안내가 보인다. (Task 2 "the freeze note is shown")

                "플레이어가 받는 피해를 0으로 합니다.",
                new Action(() => Say(BattleService.SetGod(!BattleService.God))));
        }

        // 줄 하나: 이름, 값 버튼, 설명. 다음 줄의 y를 돌려준다.
        private float Row(float y, string name, string label, string value, bool on, string note, Action onClick)

            Ui.Wrapped(content, note, 410, y + 8, ContentW - 430, 44, 15).color = Ui.Dim;
            return y + RowH;
        }
    }

using System;
using System.Globalization;
using System.Reflection;
using MelonLoader;
using UnityEngine;

namespace MOD_sWP6UL
{
    // 획득·소모의 배율. 플레이어의 호출에만 건다. 설정은 저장하지 않으며 게임을 켤 때마다 1배로 시작한다.
    // 거는 곳은 docs/superpowers/specs/2026-10-13-rate-tab-design.md 3절에서 실측했다.
    //   수련치: DataUnit.PropertyData.AddExp. 수련과 전투의 처치가 모두 지난다.
    //   공법 숙련: DataUnit.UnitInfoData.AddMartialExpInBattle. 이 메서드가 안에서 AddMartialExp를 부르므로 한 곳에만 건다.
    //   이동: UnitActionMovePlayer.OnCreate가 쓰기 전의 costDay(한 칸의 날짜 비용).
    //   전투 속도: 패치 없이 전투 장면에서 매 프레임 Time.timeScale을 맞춘다.
    internal static class RateService
    {
        public sealed class Rate
        {
            public string Key;
            public string Label;    // 탭의 줄 이름
            public string Short;    // 화면 위쪽 표시의 이름
            public string Note;
            public float[] Steps;   // 첫 칸은 항상 1
            public int Index;
            public bool Patched;
            public bool Warned;
            public MethodInfo Target;   // 걸 메서드. 전투 속도는 없다
            public string Hook;

            public float Value
            {
                get { return Steps[Index]; }
            }

            public bool On
            {
                get { return Index != 0; }
            }

            public string Text
            {
                get { return "x" + Value.ToString("0.##", CultureInfo.InvariantCulture); }
            }

#if DEVTOOLS
            public string Last = "-";   // 개발 전용: 마지막으로 바꾼 값(전 -> 후)
#endif
        }

        public static readonly Rate Exp = new Rate
        {
            Key = "exp", Label = "수련치 획득", Short = "수련", Steps = new[] { 1f, 2f, 5f, 10f, 100f },
            Note = "수련과 전투로 얻는 수련치를 곱합니다. 수련치가 다음 단계의 필요량까지 찬 인물은 오르지 않습니다.",
            Hook = "ExpPrefix",
        };

        public static readonly Rate Martial = new Rate
        {
            Key = "martial", Label = "전투 중 공법 숙련", Short = "숙련", Steps = new[] { 1f, 2f, 5f, 10f, 100f },
            Note = "전투에서 기술을 써서 얻는 숙련 경험치를 곱합니다.",
            Hook = "MartialPrefix",
        };

        public static readonly Rate Move = new Rate
        {
            Key = "move", Label = "이동의 날짜 소모", Short = "이동", Steps = new[] { 1f, 0.5f, 0.25f, 0.1f, 0f },
            Note = "대지도에서 한 칸을 갈 때 쓰는 날짜를 곱합니다. x0이면 걸어도 날짜가 흐르지 않습니다.",
            Hook = "MovePrefix",
        };

        public static readonly Rate Speed = new Rate
        {
            Key = "speed", Label = "전투 속도", Short = "속도", Steps = new[] { 1f, 1.5f, 2f, 3f },
            Note = "전투 장면의 진행 속도를 곱합니다. 전투 밖에서는 걸리지 않습니다.",
        };

        public static readonly Rate[] All = { Exp, Martial, Move, Speed };

        private static HarmonyLib.Harmony harmony;
        private static bool speedApplied;

        // 다음 단계로 넘긴다. 마지막 다음은 1배다. 결과 문장을 돌려준다.
        public static string Next(Rate rate)
        {
            int next = (rate.Index + 1) % rate.Steps.Length;
            if (next != 0)
            {
                string error = EnsurePatched(rate);
                if (error != null)
                {
                    return error;
                }
            }
            string before = rate.Text;
            rate.Index = next;
            ChangeLog.Add("배율", rate.Label, before, rate.Text, true);
            return rate.Label + ": " + rate.Text;
        }

        // 배율과 전투 보조를 모두 끈다.
        public static string Reset()
        {
            foreach (Rate rate in All)
            {
                if (rate.On)
                {
                    string before = rate.Text;
                    rate.Index = 0;
                    ChangeLog.Add("배율", rate.Label, before, rate.Text, true);
                }
            }
            BattleService.Reset();
            RestoreSpeed();
            return "배율: 모두 1배로 되돌리고 무적을 껐습니다.";
        }

        public static void OnDestroy()
        {
            RestoreSpeed();
        }

        // 그 배율을 처음 켤 때 한 번 건다. 건 뒤에는 떼지 않고 값만 본다.
        private static string EnsurePatched(Rate rate)
        {
            if (rate.Patched || rate.Hook == null)
            {
                return null;
            }
            try
            {
                if (rate.Target == null)
                {
                    rate.Target = FindTarget(rate);
                }
                if (rate.Target == null)
                {
                    throw new MissingMethodException(rate.Key);
                }
                if (harmony == null)
                {
                    harmony = new HarmonyLib.Harmony("TlToybox.rate");
                }
                harmony.Patch(rate.Target, new HarmonyLib.HarmonyMethod(
                    typeof(RateService).GetMethod(rate.Hook, BindingFlags.Static | BindingFlags.Public)));
            }
            catch (Exception e)
            {
                MelonLogger.Msg("[TlToybox] 배율 패치 실패(" + rate.Key + "): " + e);
                return "배율: 게임에 연결하지 못해 켜지 않았습니다(" + e.GetType().Name + ").";
            }
            rate.Patched = true;
            return null;
        }

        private static MethodInfo FindTarget(Rate rate)
        {
            if (rate == Exp)
            {
                return typeof(DataUnit.PropertyData).GetMethod("AddExp");
            }
            if (rate == Martial)
            {
                return typeof(DataUnit.UnitInfoData).GetMethod("AddMartialExpInBattle");
            }
            if (rate == Move)
            {
                return typeof(UnitActionMovePlayer).GetMethod("OnCreate");
            }
            return null;
        }

        private static WorldUnitBase Player
        {
            get { return g.world == null ? null : g.world.playerUnit; }
        }

        // 0 이하는 곱하지 않는다(줄어드는 호출을 키우지 않는다). 넘치면 최댓값으로 자른다.
        private static int Scale(Rate rate, int value)
        {
            if (value <= 0)
            {
                return value;
            }
            double scaled = Math.Round(value * (double)rate.Value);
            int result = scaled > int.MaxValue ? int.MaxValue : (int)scaled;
#if DEVTOOLS
            rate.Last = value + "->" + result;
#endif
            return result;
        }

        private static void Warn(Rate rate, Exception e)
        {
            if (!rate.Warned)
            {
                rate.Warned = true;
                MelonLogger.Msg("[TlToybox] 배율 처리 오류(" + rate.Key + "): " + e.Message);
            }
        }

        public static void ExpPrefix(DataUnit.PropertyData __instance, ref int v)
        {
            if (!Exp.On)
            {
                return;
            }
            try
            {
                WorldUnitBase me = Player;
                if (me != null && __instance != null && __instance.Pointer == me.data.unitData.propertyData.Pointer)
                {
                    v = Scale(Exp, v);
                }
            }
            catch (Exception e)
            {
                Warn(Exp, e);
            }
        }

        public static void MartialPrefix(DataUnit.UnitInfoData __instance, ref int exp)
        {
            if (!Martial.On)
            {
                return;
            }
            try
            {
                WorldUnitBase me = Player;
                if (me != null && __instance != null && __instance.Pointer == me.data.unitData.Pointer)
                {
                    exp = Scale(Martial, exp);
                }
            }
            catch (Exception e)
            {
                Warn(Martial, e);
            }
        }

        public static void MovePrefix(UnitActionMovePlayer __instance)
        {
            if (!Move.On)
            {
                return;
            }
            try
            {
                WorldUnitBase me = Player;
                WorldUnitBase unit = __instance == null ? null : __instance.unit;
                if (me == null || unit == null || unit.data.unitData.unitID != me.data.unitData.unitID)
                {
                    return;
                }
                float before = __instance.costDay;
                if (before <= 0f)
                {
                    return;
                }
                __instance.costDay = before * Move.Value;
#if DEVTOOLS
                Move.Last = before.ToString(CultureInfo.InvariantCulture) + "->" + __instance.costDay.ToString(CultureInfo.InvariantCulture);
#endif
            }
            catch (Exception e)
            {
                Warn(Move, e);
            }
        }

        public static bool InBattle
        {
            get
            {
                return SceneType.battle != null && SceneType.battle.battleMap != null
                    && SceneType.battle.battleMap.playerUnitCtrl != null;
            }
        }

        // 매 프레임 불린다. 전투 장면에 있는 동안만 속도를 맞추고, 벗어나거나 1배로 돌리면 되돌린다. 예외를 던지지 않는다.
        public static void Tick()
        {
            if (!Speed.On && !speedApplied)
            {
                return;
            }
            try
            {
                if (!Speed.On || !InBattle)
                {
                    RestoreSpeed();
                    return;
                }
                // 0은 게임의 일시 정지다. 풀지 않는다.
                float now = Time.timeScale;
                if (now != 0f && now != Speed.Value)
                {
                    Time.timeScale = Speed.Value;
                }
                speedApplied = true;
            }
            catch (Exception e)
            {
                Warn(Speed, e);
            }
        }

        private static void RestoreSpeed()
        {
            if (speedApplied)
            {
                speedApplied = false;
                if (Time.timeScale != 0f)
                {
                    Time.timeScale = 1f;
                }
            }
        }
    }
}

namespace MOD_sWP6UL

    // 개발 전용. 배율 탭의 검증 명령. tools/research/ui-check.ps1의 rates, rates-battle이 이 출력 모양에 의존한다.

            {

                case "rnpc":
                    return Npc();
                case "rneg":
                    {
                        var saved = g.world.playerUnit.data.unitData.propertyData;
                        int before = saved.exp;

        {

            {
                sb.Append(rate.Key).Append('=').Append(rate.Text.Substring(1)).Append(rate.Patched ? "(patched)" : "").Append(' ');
            }
            sb.Append("god=").Append(BattleService.God).Append(" damage=").Append(BattleService.Multiplier)
                .Append(" lastExp=").Append(RateService.Exp.Last)
                .Append(" lastMartial=").Append(RateService.Martial.Last)
                .Append(" lastMove=").Append(RateService.Move.Last)
                .Append(" timeScale=").Append(UnityEngine.Time.timeScale.ToString(System.Globalization.CultureInfo.InvariantCulture))
                .Append(" inBattle=").Append(RateService.InBattle);
            return sb.ToString();
        }

        private static string Npc()
        {

                }
                int before = info.propertyData.exp;

        private static string Cast(int type)
        {
            if (!RateService.InBattle)
            {
                return "not in battle";
            }
            UnitCtrlPlayer me = SceneType.battle.battleMap.playerUnitCtrl;
            if (type == 3)
            {
                me.CreateStep();
                return "CreateStep called";
            }
            return "CreateSkillAttack=" + me.CreateSkillAttack((MartialType)type);
        }

        private static string Martials()
        {
            var info = g.world.playerUnit.data.unitData;
            var sb = new StringBuilder();
            string[] names = { "left", "right", "step", "ultimate" };
            string[] ids = { info.skillLeft, info.skillRight, info.step, info.ultimate };
            for (int i = 0; i < ids.Length; i++)
            {
                DataUnit.ActionMartialData data = string.IsNullOrEmpty(ids[i]) ? null : info.GetActionMartial(ids[i]);
                sb.Append(names[i]).Append('=').Append(data == null ? -1 : data.exp).Append(' ');
            }
            return sb.ToString();
        }
