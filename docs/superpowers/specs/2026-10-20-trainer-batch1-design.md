# 트레이너 비교 1묶음(성격·아이템 소모 없음·가방 수량·영력/집중력 소모 없음) — 설계 (2026-10-20)

## 1. 의도

사용자 요청(2026-10-20): "제안 순서 1번(성격, 무한 아이템, 가방 수량 지정·버리기, 무한 영력·집중력)부터 설계해 줘." 근거는 `docs/11-trainer-comparison.md` 2.1·2.5절과 4절 1번이다. 외부 트레이너에는 있고 우리 편집기에는 없거나 일부만 있는 기능 가운데 작고 자주 쓰는 넷이다.

트레이너 코드는 옮기지 않는다. 트레이너가 부르는 게임 API 이름만 실마리로 쓰고, 동작은 우리 회차에서 실험해 확정한다(4절). 구현은 우리 규칙을 따른다: 첫 쓰기 전 백업, 쓴 뒤 다시 읽어 판정, 변경 이력, 회차 검증.

## 2. 목표 / 비목표 / 실패로 볼 것

목표
- **성격**: 능력치 탭에서 편집 대상(플레이어·NPC)의 내재 성격 1개와 외재 성격 2개를 바꾼다.
- **아이템 소모 없음**: 켜 두면 플레이어가 가방의 아이템을 "쓸" 때 수가 줄지 않는다. 범위(사용자 선택 2026-10-20 "쓰기 전부"): 단약 먹기, 전투 아이템, 비급 공부, 돌파 재료, 상자·보따리 열기, 지도에서 쓰는 부적·열쇠류.
- **가방 수량 지정·버리기**: 자원 탭의 아이템 줄에서 플레이어가 가진 수를 바로 정하고(늘리기·줄이기), 그 아이템을 모두 버린다.
- **영력·집중력 소모 없음 넓히기**: 배율 탭 `영력 소모`·`집중력 소모`를 `없음`에 두면, 기술 소모뿐 아니라 전투 중 플레이어의 영력·집중력이 줄어드는 모든 경우를 막는다.

비목표
- NPC의 가방 수량 편집(자원 탭은 플레이어 기준 그대로. 비교 문서 2.5의 "NPC 가방 편집"은 뒤로).
- 마을 창고(건목) 편집, 장비 강화·옵션 편집.
- 체력 무한(이미 `무적`이 있다), 정력 소모(비교 문서 3번 묶음).
- 트레이너식 "몇 프레임마다 값 되돌리기". 줄어드는 지점에서 막는다.
- 설정 저장. 배율처럼 켤 때마다 꺼진 상태로 시작한다(기존 배율과 같다).

실패로 볼 것
- **아이템 소모 없음이 제작 재료까지 막아** 연단·연기·부적 재료가 줄지 않거나, 반대로 제작이 이상해진다. 이 기능은 "쓰기"만 막는다. 제작(연단·연기·부적 재료)·판매·선물·퀘스트 제출은 그대로 줄어든다.
- 아이템 소모 없음이 NPC의 아이템 사용까지 막는다(플레이어만).
- 수량을 줄이거나 버릴 때 **장착 중인 장비·법보**가 사라진다. 장착품은 건드리지 않는다(4절 E3에서 장착품이 가방 자료에 들어 있는지 확인).
- 성격을 같은 외재 성격 두 개로 만들거나, 내재 칸에 외재 성격을 넣는 등 게임이 만들 수 없는 조합을 쓴다.
- 영력 소모 없음이 적의 영력까지 막는다(플레이어만).

## 4. 설계 전 실험

회차 이름은 `tb1-1020a`부터, 고정본(`-Fixture base`). 실험 명령은 `Dev/DevCommandsTrainerBatch1.cs`(배포 빌드 제외)에 둔다. 결과는 05 문서 65절에 남기고 이 문서의 가정을 고친다.

| 실험 | 방법 | 확인할 것 |
|---|---|---|
| E1 성격 | `traits`: 플레이어와 가까운 NPC 셋의 `inTrait/outTrait1/outTrait2`, `roleCreateCharacter`의 모든 줄(번호·`type`·문자열 칸 전부와 `GameTool.LS` 결과). `traitset <in> <out1> <out2>` 뒤 게임의 인물 화면(성격 표시)과 저장·불러오기 뒤 값 | 번호 범위·종류 구분 칸·이름 칸, 화면 반영, 다른 값(파생 능력치)이 같이 바뀌어야 하는지 |
| E2 아이템 사용 | Harmony로 3절의 소모 메서드 모두에 기록용 접두를 붙이는 `costtrace on`. 막을 쪽(지도에서 단약 먹기 `UnitActionPropUse`, 전투에서 아이템 쓰기, 비급 공부 `UnitActionPropMartialStudy`, 돌파 재료를 넣는 돌파, 상자·보따리 열기, 지도용 부적·열쇠)과 막지 않을 쪽(연단 재료 넣기·연기·부적 그리기, 상점 팔기, 선물, 퀘스트 제출)을 차례로 하고 어느 메서드가 어떤 호출 순서로 불리는지 본다 | 막을 쪽만 가려내는 지점(후보: `UnitActionPropUse.CostPropItem` 건너뛰기. 비급 공부·돌파·전투 아이템은 별도 경로일 수 있어 경로마다 패치가 하나씩 늘 수 있다), 단약 재사용 대기(`GetPropsPillCD`)를 건드려야 하는지(비목표면 그대로) |
| E3 가방 | 겹치는 아이템(단약)과 겹치지 않는 아이템(장비·법보)에 `bagset <id> <n>`(늘림은 `RewardPropItem`, 줄임은 `DelProps(id, 차이)`)과 `bagdel <id>`. 장착 중인 법보와 같은 번호의 법보가 가방에도 있을 때 `GetPropsNum`·`DelProps`가 장착품을 세는지·지우는지 | 차이 방식이 두 종류 모두에 맞는지, 장착품 보호 방법(장착 soleID를 빼고 지우기 등), 가방 칸 넘침 |
| E4 영력·집중력 | 전투에서 `mptrace on`: `AddMP/AddSP`와 `set_mp/set_sp` 호출을 기록하며 기술 쓰기, 적의 영력 깎기 기술 맞기, 연요호 쓰기 | 막을 지점이 `AddMP/AddSP`의 음수 접두로 충분한지, 플레이어 단위 판별(`playerUnitCtrl.data`) |

## 5. 화면

### 5.1 성격 — 능력치 탭 여섯째 분류

- 분류 단추 줄에 `성격`(`AttrCat5`)을 더한다(156 간격으로 여섯째, 폭 안에 들어간다).
- 고르면 표 대신 세 줄: `내재 성격`, `외재 성격 1`, `외재 성격 2`. 줄마다 지금 값의 이름과, 고를 수 있는 성격을 칩으로 늘어놓는다(`Trait<칸>_<번호>`, 칸은 `in`·`out1`·`out2`). 지금 값의 칩은 켜진 모양.
- 칩을 누르면 바로 쓴다. 외재 1·2에서 다른 칸과 같은 성격 칩은 꺼 둔다(누를 수 없음).
- 아래에 안내 한 줄: "성격은 대화·사건 선택지와 NPC의 행동에 영향을 줍니다." (E1에서 다른 영향이 확인되면 고친다.)
- 결과 문장: `성격(<이름>): 외재 성격 1 <전> -> <후>`.

### 5.2 아이템 소모 없음 — 배율 탭 한 줄

- 배율 탭에 줄 `아이템 소모`(키 `itemUse`, 단계 x1·없음). 설명: "플레이어가 아이템을 써도(단약·전투 아이템·비급 공부·돌파 재료·상자 열기·부적) 수가 줄지 않습니다. 제작 재료·판매·선물·퀘스트 제출은 그대로 줄어듭니다."
- 다른 배율과 같이 켤 때마다 x1에서 시작한다.

### 5.3 가방 수량 지정·버리기 — 자원 탭 아이템 줄

- 아이템 줄(화폐·비급 즐겨찾기 줄 제외)의 `보유` 칸을 숫자 칸(`ResOwned<번호>`)으로 바꾼다. 숫자를 쓰고 Enter(또는 칸을 떠나면) 그 수가 되도록 차이만큼 지급하거나 지운다.
- `보유` 칸 오른쪽에 `버리기`(`ResDrop<번호>`, 가진 것이 없으면 꺼짐). 두 번 누르기(`Confirm`): 첫 누름에 "<이름> n개를 모두 버립니다. 한 번 더 누르면 버립니다."
- 0을 쓰면 버리기와 같다(두 번 누르기 없이. 숫자를 직접 쓴 것이 확인이다 — 내 판단).
- 장착 중인 것은 세지 않고 지우지 않는다(E3 결과로 방법 확정).
- **겹치지 않는 아이템(장비·법보)을 줄일 때의 순서**(사용자 선택 2026-10-20 "약한 것부터"): 장착하지 않은 것 가운데 강화·옵션이 없거나 낮은 것부터 지운다. 버리기는 장착하지 않은 것을 모두 지우되, 첫 누름의 확인 문구에 "강화·옵션이 붙은 것 n개 포함"을 넣는다(n이 0이면 뺀다). 장착품이 있으면 결과 문장 끝에 "장착 중인 n개는 그대로 두었습니다."
- 결과 문장: `<이름>: n개 -> m개`. 가방이 모자라 다 늘지 않으면 지금의 지급 문장과 같이 알린다.

### 5.4 영력·집중력 소모 없음 — 배율 탭 설명만 바뀜

- 줄과 단계는 그대로. `없음` 단계일 때만 전투 중 플레이어의 영력·집중력이 줄어드는 모든 호출을 막는다. 설명을 고친다: "전투에서 무예·절기·신법·신통과 호천안 기술이 쓰는 영력을 곱합니다. 없음이면 전투 중 영력이 줄지 않습니다(적의 영력 깎기 포함)."
- x0.5 등 다른 단계는 지금처럼 기술 소모만 곱한다(받는 깎기는 그대로).

## 6. 동작 규칙

- **성격**: 쓰기 전 검사 — 번호가 그 칸의 종류인지(E1의 종류 칸), 외재 둘이 다른지. 막는 조합은 이 둘뿐이다(검토 뒤 내 판단). E1에서 인물 만들기 화면(`UICreateRole` 계열)이 함께 고를 수 없게 하는 외재 쌍이 확인되면 그 쌍도 칩을 꺼서 막는다. 지금 값이 목록 밖 번호면 칸에 `목록에 없는 번호 n`으로 보이고, 목록 안의 칩으로만 바꿀 수 있다(검토 뒤 내 판단). 백업(`SaveBackup.EnsureOnce`) → 칸 쓰기 → 다시 읽어 판정 → 이력(분류 `성격`). 편집 대상이 NPC면 그 NPC에 쓴다(능력치 탭의 다른 줄과 같다). `EditService.SetTrait(unit, slot, id)`.
- **아이템 소모 없음**: `RateService`에 켬/끔 한 줄(`Rate`, 단계 `{1f, 0f}`, `ZeroText "없음"`). 패치 대상은 E2에서 정하며, 기본 후보는 `UnitActionPropUse.CostPropItem` 접두에서 `__instance`의 유닛이 플레이어면 `false`를 돌려 건너뛰는 것. 전투 아이템이 다른 경로면 그 경로를 더한다. 처음 켤 때 패치를 붙이고 떼지 않는다(기존 `Hook` 방식). `WorldUnitData.CostPropItem` 전체를 막는 방법은 쓰지 않는다(제작 재료가 같이 막힌다).
- **가방 수량**: `BagService.SetCount(unit, propsId, n)`와 `BagService.Drop(unit, propsId)`. 지금 수 c(장착품 제외)와 비교해 n>c면 `RewardPropItem(id, n−c)`, n<c면 겹치는 아이템은 `DelProps(id, c−n)`, 겹치지 않는 아이템은 soleID 단위로 장착 아닌 것 가운데 약한 것부터(강화 단계·옵션 수가 작은 순, 같으면 가방 순서. "약함"을 재는 칸은 E3에서 법보 `PropsArtifact.level`·`grade`, 장비 강화·옵션 칸을 확인해 정한다) `DelProps(soleID)`. 백업 → 쓰기 → 다시 세어 판정 → 이력(분류 `아이템 <이름>(<번호>)`, 지금 지급 이력과 같은 꼴). n의 범위 0~99999(내 판단).
- **영력·집중력**: `UnitDataBase.AddMP`·`AddSP` 접두. `MpCost`(또는 `SpCost`)가 켜져 있고 값이 0이며, 전투 중이고 `__instance`가 플레이어 전투 단위의 자료이며, 넘어온 값이 음수면 건너뛴다. E4에서 기술 소모가 `set_mp`로 바로 쓰이면 지금의 기술값 곱하기(`TickSkillValues`)가 그쪽을 맡으므로 그대로 둔다.

## 7. 검증

- 검사 `ui-check.ps1`에 부분 넷: `traits`, `itemuse`, `bagcount`, `mpnone`.
  - `traits`: 성격 분류가 보이는지, 세 칸의 칩, 칩 누르기 → 저장값·이력, 같은 외재 칩이 꺼지는지, NPC 대상에서도 되는지.
  - `itemuse`: 켜고 단약 먹기·전투 아이템·비급 공부·돌파 재료·상자 열기 → 수 그대로, 연단 재료 넣기·판매 → 줄어듦, 끄면 다시 줄어듦.
  - `bagcount`: 겹치는 아이템 수 늘리기·줄이기·0, 겹치지 않는 아이템 늘리기·줄이기(강화한 것과 안 한 것을 섞어 두고 안 한 것부터 지워지는지), 버리기 두 번 누르기와 "강화된 것 포함" 문구, 장착 법보가 남는지, 이력.
  - `mpnone`: 없음에서 기술 쓰기·적의 영력 깎기 뒤 영력이 그대로, x0.5에서는 기술 소모만 반으로, 적의 영력은 줄어듦.
- 기존 검사 `rates`(줄 수·정규식), `resources` 계열이 깨지지 않는지 다시 돌린다.
- 배포 구성 경고 0, 회차 `-End`의 `SAVE RESTORED AND IDENTICAL`.

## 8. 결정한 것(내 판단) / 빌더에게 남긴 것

사용자 선택: 아이템 소모 없음의 범위는 "쓰기 전부", 장비·법보 줄이기는 "약한 것부터"(버리기는 강화된 것 포함을 알림).
내 판단: 성격은 능력치 탭 여섯째 분류, 아이템 소모 없음은 배율 탭의 켬/끔 줄(쓰기만, 제작·판매는 그대로), 가방 수량은 자원 탭 `보유` 칸을 숫자 칸으로 + `버리기` 두 번 누르기, 0 입력은 확인 없이 버리기, 영력·집중력은 새 줄 없이 기존 `없음` 단계를 넓힌다, 설정은 저장하지 않는다, 플레이어만(성격은 편집 대상). 검토 뒤 더한 것: 성격은 외재 중복·종류 어긋남만 막고(인물 만들기 화면의 짝 규칙이 E1에서 나오면 더한다), 목록 밖 번호는 보이기만 한다.
빌더에게: 칩 배치와 줄 높이, 실험 명령의 출력 꼴, 패치 대상의 최종 선택(E2·E4 뒤).
